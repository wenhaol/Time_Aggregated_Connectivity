Abstract

Connectivity maintenance is critical for networked robot teams to exchange information and coordinate actions, yet enforcing persistent global connectivity can be unnecessarily restrictive when communication ranges are limited and teams operate at scale. This work introduces a motion-coordination framework that maintains time-aggregated connectivity, allowing temporary disconnections while ensuring information can still flow across the team over each time window. The framework combines (1) a time-window aggregated minimum spanning tree (TWA-MST) for selecting low-effort reconnection edges and (2) adaptive prescribed-time control barrier functions (adaptive PT-CBF) for guaranteed and timely pairwise reconnection. Both analysis and experiments show improved task efficiency with reliable connectivity recovery.

Method Overview

The approach is implemented as a coordination layer on top of robots' nominal trajectories. It intervenes only when reconnection is needed, so robots can follow their task plans with minimum additional effort.

  1. TWA-MST scheduler: for each candidate robot pair, aggregate predicted edge cost over a finite window, then choose a sparse set of reconnection edges with low total effort.
  2. Adaptive PT-CBF controller: once an edge is triggered, adapt the prescribed-time barrier parameters online so reconnection remains feasible and timely while reducing unnecessary control deviation.
  3. Dual-layer communication model: long-range links preserve coordination exchange, while short-range links are re-established intermittently to guarantee time-aggregated connectivity.

Core scheduling metric in the paper: w̄ij(t) = min_{τ∈[t,t+T_w]} d_ij(τ).

Results Snapshot

In a cluttered indoor simulation (workspace 32×54 m, N = 8 robots), the method improves task efficiency while preserving communication objectives. Compared with PT-CBF, FT-CBF, MCCST, TSMST, and random spanning-tree baselines, the proposed framework reduces additional travel/control effort and maintains robust reconnection behavior.
